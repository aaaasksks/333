# Конспекты по Python для начинающих

Четыре темы идут по порядку. Сначала разберите классы и методы, затем операции с MySQL, потом HTML-парсер. В последнем конспекте эти знания объединяются в один проект.

1. [01_oop_python.md](01_oop_python.md) - классы, методы, наследование и исключения.
2. [02_mysql_python.md](02_mysql_python.md) - создание базы, SQL, подключение Python, добавление, чтение, изменение и удаление.
3. [03_parser_stdlib.md](03_parser_stdlib.md) - загрузка и разбор HTML без сторонних библиотек.
4. [04_full_project.md](04_full_project.md) - парсер каталога с классами, обработкой ошибок и сохранением товаров в MySQL.

## Файлы для практики

В папке `examples` находятся исходные файлы примеров:

- `oop_demo.py` - пример ООП, запускается без установки пакетов.
- `catalog.html` - учебная страница с тремя товарами.
- `parser_demo.py` - парсер каталога, работает без интернета и сторонних библиотек.
- `setup.sql` - база, учебный пользователь MySQL и таблицы.
- `mysql_demo.py` - четыре основные операции с MySQL.
- `project.py` - итоговый проект.

## Как начать

Установите Python 3.10 или новее, откройте терминал в этой папке и проверьте примеры без базы:

```bash
python examples/oop_demo.py
python examples/parser_demo.py
```

Для примеров с MySQL потребуется работающий MySQL Server. Выполните SQL из `examples/setup.sql` от имени пользователя с правами администратора и установите драйвер:

```bash
python -m pip install mysql-connector-python
python examples/mysql_demo.py
python examples/project.py
```

В `setup.sql` указаны учебные логин `student` и пароль `study_pass`. Они предназначены только для локальной практики. Не используйте этот пароль для реальных баз.

Для занятий удобно давать тему в таком порядке: объяснение, короткий пример, самостоятельный запуск, изменение примера, небольшое задание. Каждый конспект содержит задания и разбор типичных ошибок.
